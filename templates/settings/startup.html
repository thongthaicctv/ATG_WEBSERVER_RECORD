Hướng dẫn cài đặt chạy ẩn

  1. Máy cài mới chỉ cần ATG_WEBSERVER.exe, đặt trong một thư mục cố định, ví dụ D:\PYTHON-TCR\EXE\ATG_WEBSERVER. Không copy webserver_config.json từ máy khác hoặc user Windows khác.
  2. Chạy lần đầu: mở WebServer trên chính máy đó (http://127.0.0.1:<port>) và cấu hình Database. webserver_config.json sẽ được tạo và mã hóa riêng cho Windows user hiện tại.
  3. Đăng nhập root, vào Cài đặt WebServer, nhập port, DDNS nếu có và các thư mục gốc lưu video. Bấm Lưu cấu hình.
  4. Vào trang này, bật Tự khởi động ATG_DIGICAM WebServer cùng Windows và bật Chạy thu nhỏ khi khởi động, sau đó bấm Lưu cài đặt.
  5. Thoát app bằng menu tray, mở lại hoặc khởi động lại Windows để kiểm tra. Khi chạy đúng, app không hiện cửa sổ, chỉ có icon tray và thông báo WebServer đang chạy.
  6. Nếu đổi vị trí file exe sang thư mục khác, mở lại trang này và bấm Lưu cài đặt để cập nhật shortcut/registry.
